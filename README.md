# Joshua Toluse Onibiyo

Portfolio site, served by GitHub Pages. Plain HTML and CSS, no build step.

- `index.html`: the portfolio
- `adventist-hymnal/privacy/`: Adventist Hymnal privacy policy (linked from Google Play)
- `lamp/privacy/`: Lamp (Bible app) privacy policy (linked from Google Play)
- `sapaproof/privacy/`: SapaProof privacy policy (linked from Google Play)
- `assets/`: shared styles and images
